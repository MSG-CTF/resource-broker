# GCP 무료 체험판 크레딧 읽기

Broker 계정 목록을 열면 현재 Chrome 프로필로 Google Cloud 결제 > 크레딧 화면을 열고 사용 가능한 무료 체험판 잔액을 읽는 확장 기능이다. 읽기에 성공하면 Broker Admin API가 결제 계정별 최신 잔액과 관측 시각을 DB에 저장한다. 다른 관리자는 확장 기능이 없어도 저장된 값을 계정 목록에서 볼 수 있다. Google 비밀번호, 쿠키, 액세스 토큰은 읽거나 전달하지 않는다.

## 설치

1. `nhjangh@gmail.com`으로 Google Cloud 콘솔에 로그인된 **같은 Chrome 프로필**에서 `chrome://extensions`를 연다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**에서 이 폴더(`browser-extension/gcp-credit`)를 선택한다.
3. `https://broker.mjsec.kr/`을 새로고침한다.
4. 이종윤, 허준하, 정유찬, 이승환, 김규민, 최윤호, 최진웅, 강지원, 나건하 GCP 행의 `잔여 크레딧`에 Google 결제 > 크레딧 화면의 사용 가능 금액과 조회 시각이 자동으로 나타난다. 계정 목록의 `새로고침` 버튼을 누르면 다시 조회한다.

나머지 GCP 계정은 `조회불가`로 표시한다. 김예슬 계정은 연결하지 않았다. 로그인 만료, 결제 화면 접근 거부 또는 Google의 화면 구조 변경 시에는 마지막으로 저장된 값이 있으면 그대로 표시하고, 없으면 `조회불가`로 표시한다. 계정 목록을 불러올 때마다 결제 계정별 Google 탭을 두 개씩 백그라운드에서 열고 조회 후 닫는다.

이 기능은 Google의 공개 잔액 API를 쓰지 않는다. Google 콘솔 화면 구조에 의존하므로 화면 변경 후에는 선택자를 갱신해야 한다. 확장 기능 파일을 변경한 뒤에는 `chrome://extensions`에서 확장 기능을 새로고침해야 한다.
